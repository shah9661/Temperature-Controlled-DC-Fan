# 🌡️ Temperature-Controlled DC Fan

An analog circuit that automatically controls a DC fan based on ambient temperature, using an **LM35 temperature sensor**, **LM358 op-amp**, and an **NPN transistor** driver stage.

## 📌 Overview

The LM35 outputs a voltage proportional to temperature. The LM358 compares this against an adjustable threshold (set via potentiometer) and drives a 2N2222 transistor, which switches the DC fan on. A flyback diode protects the transistor from voltage spikes generated by the motor.

> **Note:** As wired, the LM358 acts as a comparator — the fan switches **ON/OFF** around the set threshold rather than varying speed continuously. For true proportional speed control, a PWM-based approach would be needed (see Future Improvements).

## 🔌 Wiring

**LM35** → Pin1: +5V · Pin2 (VOUT): LM358 input · Pin3: GND

**LM358** → Pin3 (non-inv): LM35 VOUT · Pin2 (inv): Potentiometer wiper · Pin4: GND · Pin8: +5V · Pin1 (out): 1 kΩ → transistor base

**Potentiometer (10 kΩ)** → Ends: +5V & GND · Wiper: LM358 input

**2N2222** → Base: LM358 output via 1 kΩ · Collector: Fan (−) · Emitter: GND
*(Verify pinout against your specific transistor's datasheet.)*

**DC Fan** → (+): +12V · (−): Transistor collector

**1N4007** → Across the fan, cathode to +12V, anode to fan(−)/collector — protects against inductive flyback voltage

**Grounds:** +5V and +12V supply grounds are tied together.

## ⚙️ Working Principle

1. **Sensing** — LM35 outputs ~10 mV/°C (e.g. 25°C ≈ 250 mV, 40°C ≈ 400 mV).
2. **Comparison** — LM358 compares this voltage to the threshold set by the potentiometer.
3. **Switching** — LM358 output drives the 2N2222 base through a 1 kΩ resistor.
4. **Fan control** — The transistor switches +12V current through the fan on/off based on the comparison result.
5. **Protection** — The 1N4007 diode absorbs the voltage spike when the motor's current path changes.

```
Temperature → LM35 → Voltage → LM358 (vs. threshold) → 2N2222 → DC Fan
```

## 🧪 Testing

1. Power the circuit with +5V and +12V.
2. Adjust the potentiometer to set the desired trigger temperature.
3. Vary the temperature around the LM35 and observe the fan response.
4. Confirm clean switching behavior and correct diode/transistor operation.
